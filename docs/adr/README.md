# Architecture Decision Records

Los ADR documentan decisiones arquitectónicas relevantes, su contexto y sus consecuencias.

## Convención

- Nombre: `NNN-titulo-corto.md`
- Estados: Propuesto, Aceptado, Rechazado, Reemplazado
- Una decisión por archivo
- Cambiar una decisión requiere un ADR nuevo y puede referenciar el anterior
