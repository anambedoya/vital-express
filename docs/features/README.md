# Feature Specifications

Cada feature tendrá un documento independiente con el siguiente conjunto mínimo:

- objetivo y alcance
- actores
- reglas de negocio
- criterios de aceptación
- contratos de API o eventos
- estados y transiciones
- casos de error
- datos sensibles
- métricas y telemetría
- dependencias
- pruebas
- decisiones pendientes
